# Surrounded ⚔️

**Surrounded** — динамічний 2D Roguelite Arena Survival у ретро піксель-арт стилі, розроблений на рушії **Defold**.

Вам належить відбивати нескінченні хвилі монстрів у закритому підземеллі, прокачувати стихійні аури, блискавки та характеристики, відкривати скрині з нагородами та перемагати грізних міні-босів.

---

## 🎮 Особливості гри

- 🗡️ **Орбітальна бойова система**: леза обертаються довкола героя, розсікаючи ворогів і відкидаючи їх назад.
- 🌳 **Дерево навичок (Skill Tree)**:
  - **Стихійні аури**: вибір між Вогняною короною полум'я (тягнеться до героя) або Морозяною завірюхою (хвилі назовні зі сповільненням).
  - **Гілка Блискавок**: авто-удар блискавки, ланцюговий розряд та нищівна гроза.
  - **Гілка Майстерності**: магнетизм кристалів, титанічна живучість та лють швидкості.
- 👾 **Розумний AI та хвилі монстрів**:
  - Пошук шляху A* (8 напрямків) без застрягання у стінах.
  - Різноманітний ростер: Слимаки, Скелети, Очі, Зомбі.
  - Міні-боси: Пекельний гончак, Некромант, Лицар смерті.
- 💎 **Скрині нагород**: випадковий вибір із 3 карток покращень.
- 🎨 **Повністю кастомний Pixel-Art UI**: стилізовані 3D-кнопки, фрейми таймера, лічильника кілів та бейджів зі `slice9`.

---

## 🕹️ Керування

- **Миша / Тач**: клік або утримання лівої кнопки миші для переміщення героя.
- **HUD [SKILLS]**: відкрити дерево навичок при отриманні очок рівня (гра автоматично ставиться на паузу).
- **HUD [PAUSE] / Esc**: меню паузи.
